# Integration logos

Small marks shown next to each integration's name in Settings and on the
profile page (`src/components/integration-logo.tsx`). Every name and mark here
is a trademark of its owner, used only to identify the service the integration
connects to. Consultainer isn't affiliated with or endorsed by any of them.

Files are unaltered apart from sizing: a `viewBox` added or cropped to the
symbol, a `fill` set to the brand colour, or a light/dark pair split out of one
file.
