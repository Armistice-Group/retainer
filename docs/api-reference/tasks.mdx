---
title: Tasks
description: List, create, update, and delete tasks on a project, and comment on them
---

## List a project's tasks

```
GET /api/v1/projects/{id}/tasks
```

## Create a task

```
POST /api/v1/projects/{id}/tasks
```

<ParamField body="title" type="string" required />
<ParamField body="description" type="string" />
<ParamField body="assigneeId" type="string">
  A user ID to assign the task to. Notifies the assignee.
</ParamField>

```bash
curl -X POST https://consultainer.app/api/v1/projects/proj_123/tasks \
  -H "Authorization: Bearer ch_live_..." \
  -H "Content-Type: application/json" \
  -d '{"title": "Set up staging environment"}'
```

## Update a task

```
PATCH /api/v1/tasks/{id}
```

<ParamField body="status" type="string">
  `TODO`, `IN_PROGRESS`, or `DONE`.
</ParamField>
<ParamField body="assigneeId" type="string">
  Pass `null` to unassign.
</ParamField>

## Delete a task

```
DELETE /api/v1/tasks/{id}
```

## List a task's comments

```
GET /api/v1/tasks/{id}/comments
```

Comments are internal unless shared with the client (see `shareWithClient`). Each comment
has `id`, `body`, `createdAt`, `author` (`{ id, name }`, or `null` if the author
has left or isn't a member), `authorName`, `source` (`app`, or `linear` for
comments pulled in from the task's Linear issue), and `linearUrl` when the
comment is on the Linear issue too.

## Comment on a task

```
POST /api/v1/tasks/{id}/comments
```

<ParamField body="body" type="string" required>
  Up to 5,000 characters. Notifies the task's assignee and watchers. Mention
  someone with `@[Name](user:USER_ID)` to notify them directly (and make them a
  watcher); mentions of people who can't see the project are ignored.
</ParamField>
<ParamField body="shareWithClient" type="boolean" default="false">
  Show the comment on the project's client link. Only appears there while the
  project's share link shows tasks.
</ParamField>
<ParamField body="postToLinear" type="boolean" default="true">
  On a task linked to a Linear issue, also post the comment there. Ignored for
  unlinked tasks.
</ParamField>

```bash
curl -X POST https://consultainer.app/api/v1/tasks/task_123/comments \
  -H "Authorization: Bearer ch_live_..." \
  -H "Content-Type: application/json" \
  -d '{"body": "Staging is ready for review.", "postToLinear": false}'
```

## Delete a comment

```
DELETE /api/v1/tasks/{id}/comments/{commentId}
```

Authors can delete their own comments; owners and admins can delete any. A
copy already posted to Linear stays there.
