## List clients

```
GET /api/v1/clients
```

Returns every client in your organization.

```bash
curl https://<your-instance>/api/v1/clients \
  -H "Authorization: Bearer ch_live_..."
```

## Create a client

```
POST /api/v1/clients
```

  -H "Authorization: Bearer ch_live_..." \
