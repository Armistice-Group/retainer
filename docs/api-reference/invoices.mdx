## List invoices

```
GET /api/v1/invoices
```

Any role. Returns the organization's invoices, newest first, each with its
`client` (`{ id, name }`). Owner and admin keys get every invoice. A member's
key doesn't get invoices with a line on a confidential project the member
isn't on.

<ParamField query="status" type="string">
  Only `DRAFT`, `SENT`, `PAID`, or `VOID` invoices. Any other value is
  ignored. A `VOID` invoice keeps its lines and total, but the time
  entries, milestones and expenses on it were released when it was voided
  and can be generated onto a new invoice.
</ParamField>

```bash
curl "https://<your-instance>/api/v1/invoices?status=SENT" \
  -H "Authorization: Bearer ch_live_..."
```

```json
{
  "invoices": [
    {
      "id": "cm9...",
      "number": "INV-0042",
      "status": "SENT",
      "issueDate": "2026-08-01T00:00:00.000Z",
      "dueDate": "2026-08-31T00:00:00.000Z",
      "paymentTerms": "NET30",
      "subtotal": "5250",
      "taxAmount": "0",
      "total": "5250",
      "currency": "USD",
      "kind": "STANDARD",
      "amountPaid": "2000.00",
      "creditApplied": "0.00",
      "balanceDue": "3250.00",
      "paidAt": null,
      "firstViewedAt": "2026-08-02T16:40:12.000Z",
      "viewCount": 3,
      "client": { "id": "cm9...", "name": "Fintra Labs" },
      "...": "..."
    }
  ]
}
```

`amountPaid` is the sum of the payments recorded on the invoice and
`creditApplied` the [client credit](/concepts/deposits-and-credit) applied to
it; `balanceDue` is `total` minus both (never below `0.00`, and `0.00` for a
`VOID` invoice). A partly paid invoice stays `SENT` until `balanceDue`
reaches `0.00`. `kind` is `STANDARD`, or `DEPOSIT` for a
[deposit invoice](/concepts/deposits-and-credit#deposits). `paidAt` is when
the invoice became paid in full (by hand, or when an online payment went
through), or `null`. `firstViewedAt`, `lastViewedAt` and
`viewCount` track when the client opened the invoice. To find overdue invoices, look for `SENT` invoices whose
`dueDate` has passed (the MCP `list_invoices` tool returns `isOverdue` and
`daysOverdue` for you).

## Generate an invoice

```
POST /api/v1/invoices/generate
```

Owner/admin only. Creates a draft from unbilled time entries, completed
milestones, and/or approved expenses, the same as **Generate invoice** in
the app. Returns `201` with `{ "invoice": { ... } }`, including its `id`,
`number` and computed `subtotal`, `taxAmount` and `total`. Review and send the draft in the app, or with the MCP
`email_invoice` or `mark_invoice_sent` tools.

<ParamField body="clientId" type="string" required />
<ParamField body="timeEntryIds" type="string[]">
  Billable time entries not yet on an invoice, on this client's projects. If
  your organization requires timesheet approval, the time must be approved.
</ParamField>
<ParamField body="milestoneIds" type="string[]">
  Completed milestones not yet on an invoice.
</ParamField>
<ParamField body="expenseIds" type="string[]">
  Approved expenses not yet on an invoice.
</ParamField>
<ParamField body="issueDate" type="string" required>
  `YYYY-MM-DD`.
</ParamField>
<ParamField body="dueDate" type="string">
  `YYYY-MM-DD`. Defaults to `issueDate` plus the payment terms. Required when
  `paymentTerms` is `CUSTOM`.
</ParamField>
<ParamField body="paymentTerms" type="string">
  `DUE_ON_RECEIPT`, `NET15`, `NET30`, `NET45`, `NET60`, `NET90`, or `CUSTOM`.
  Defaults to the project's terms when every item is from one project that
  sets them, otherwise the client's, otherwise the organization's default.
</ParamField>
<ParamField body="poNumber" type="string">Up to 100 characters.</ParamField>
<ParamField body="taxRate" type="number" default="0">
  Percent, 0 to 100.
</ParamField>
<ParamField body="notes" type="string">Up to 2,000 characters.</ParamField>

At least one of `timeEntryIds`, `milestoneIds`, or `expenseIds` is required.
IDs that don't qualify (already invoiced, not billable, on another client's
project, and so on) are skipped. The invoice uses the organization's default
currency.

```bash
curl -X POST https://<your-instance>/api/v1/invoices/generate \
  -H "Authorization: Bearer ch_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "clientId": "cm9...",
    "timeEntryIds": ["cm9...", "cm9..."],
    "issueDate": "2026-08-01",
    "paymentTerms": "NET30"
  }'
```

**Errors**

| Status | Message | Fix |
| --- | --- | --- |
| `403` | `Only owners and admins can generate invoices.` | Use an owner or admin key. |
| `422` | `{ "timeEntryIds": ["Select at least one time entry, milestone, or expense"] }` | Send at least one ID. |
| `422` | `Client not found.` | Check `clientId`. |
| `422` | `No eligible unbilled time entries, milestones, or expenses were selected.` | None of the IDs qualified. Check they're on this client's projects, billable, approved, and not already invoiced. |
| `422` | `Custom payment terms need a due date.` | Send `dueDate` with `CUSTOM` terms. |

## List an invoice's payments

```
GET /api/v1/invoices/{id}/payments
```

Any role that can see the invoice. Returns its `amountPaid`, `creditApplied`
and `balanceDue`, plus:

- `payments`: each with `amount`, `currency`, `receivedAt`, `source`
  (`MANUAL`, `STRIPE`, `MERCURY` or `QUICKBOOKS`), `method`, `reference`,
  `note` and `recordedBy` (a name, or `null` for payments recorded by an
  integration), newest first.
- `creditApplications`: client credit applied to the invoice.
- `creditNotes`: credit notes issued against it.

Returns `404` with `Invoice not found.` for an invoice in another
organization or one the key can't see.

## Record a payment

```
POST /api/v1/invoices/{id}/payments
```

Owner/admin only. Records money received against a sent invoice, the same as
**Record payment** in the app. The invoice becomes `PAID` when its balance
reaches zero (with the *invoice paid* alert); a part payment leaves it `SENT`
and sends the *part payment received* alert. Returns `201` with
`{ "payment": { ... }, "invoice": { ... } }`; `invoice` includes the new
`amountPaid` and `balanceDue`.

<ParamField body="amount" type="number" required>
  In the invoice's currency, greater than zero, to the cent. Can't be more
  than `balanceDue`.
</ParamField>
<ParamField body="receivedAt" type="string">
  `YYYY-MM-DD`. Defaults to today.
</ParamField>
<ParamField body="method" type="string">For example `Wire`. Up to 100 characters.</ParamField>
<ParamField body="reference" type="string">For example a check number. Up to 200 characters.</ParamField>
<ParamField body="note" type="string">Up to 1,000 characters.</ParamField>

```bash
curl -X POST https://<your-instance>/api/v1/invoices/cm9.../payments \
  -H "Authorization: Bearer ch_live_..." \
  -H "Content-Type: application/json" \
  -d '{ "amount": 2000, "receivedAt": "2026-08-20", "method": "Wire" }'
```

**Errors**

| Status | Message | Fix |
| --- | --- | --- |
| `403` | `Only owners and admins can record payments.` | Use an owner or admin key. |
| `404` | `Invoice not found.` | Check the id, and that the key can see the invoice. |
| `422` | `{ "amount": ["Amount must be greater than zero"] }` | Send a positive `amount`. |
| `422` | `That's more than the $3,250.00 still due on this invoice.` | Record at most `balanceDue`. |
| `422` | `Send the invoice before recording a payment.` | The invoice is a draft. |
| `422` | `This invoice is already paid in full.` | Nothing is due. |
| `422` | `This invoice is void.` | Void invoices can't be paid. |
| `422` | `Enter an amount greater than zero, to the cent.` | Use at most two decimal places. |

To delete a payment recorded by mistake, use the invoice's **Payments** card in
the app.
