## 1. Create your workspace

Sign up at [consultainer.app/signup](https://consultainer.app/signup). Signing
up creates a new organization — the Free plan works for real, indefinitely, for
up to 2 clients and 1 user, no credit card required.

## 2. Add a client

From **Clients**, add the client you're billing. Add a contact with an email
and mark it primary if you want billing correspondence (like a contractor
approval request) to go to the right person.

## 3. Create a project

From **Projects**, create a project under that client and pick a billing type:

- **Hourly** — billed from logged time.
- **Flat fee** — a fixed price for the whole engagement.
- **Milestone-based** — billed per deliverable as milestones are completed.

Add teammates to the project with a bill rate. If your organization only has
one member, you're added to new projects automatically.

## 4. Log time

From **Time**, log hours against the project (and optionally a task). Hours
default to billable — mark an entry non-billable if it shouldn't be invoiced.

## 5. Generate an invoice

From **Invoices → New**, pick the client. Consultainer shows everything
eligible to bill: unbilled billable time, completed milestones, and approved
expenses. Select what you want on this invoice, set payment terms and a PO
number if needed, and generate a draft.

From the draft you can edit line items, mark it sent, download a PDF, or push
it straight to QuickBooks if you've connected that integration.
