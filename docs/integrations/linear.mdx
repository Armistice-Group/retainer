---
title: Linear
description: Pull Linear issues into a project's task list
---

Connect Linear from **Settings → Integrations**. An owner or admin
authorizes access via OAuth.

## What syncs

Once connected and linked to a project, Linear issues pull in as tasks on
that project — real backlog items, not a generic bucket for hours. Time can
be logged against a synced task the same as any other.

<Note>
  Today this is a one-way, read-only pull from Linear into Consultainer.
  Editing or completing a task in Consultainer doesn't push changes back to
  Linear yet.
</Note>

## Disconnecting

Disconnecting Linear from Settings → Integrations stops future syncs;
tasks already pulled in stay as they are.
