title: Linear
description: Sync a project's tasks with Linear issues, both ways
---

## Connecting

In **Settings → Integrations**, an owner adds the instance's Linear OAuth app
credentials (the card shows the callback URL to register), then an owner or
admin clicks **Connect**. Consultainer asks for read and write access.

## Linking a project

On a project's page, **Link Linear** picks:

- **Team** — required.
- **Linear project** — optional. Only issues in that Linear project sync.
- **Labels** — optional. Only issues with at least one of them sync.

Several Consultainer projects can link to the same team — one per client,
say — each narrowed by its own Linear project or labels. If an issue matches
more than one, it stays with the project that pulled it in first.

**Sync now** pulls matching issues in as tasks and updates ones already
pulled in (title, description, status, assignee — matched by email). It also
pulls in comments from those issues, and sends open tasks that don't have an
issue yet. Linked projects also sync on their own every hour.

## Live updates (webhooks)

To see Linear changes right away instead of on the next sync, turn on
webhooks in your Linear OAuth app:

1. In Linear, open the OAuth app (**Settings → API → OAuth applications**) and
   enable **Webhooks** with the URL shown under **Live updates** in
   Consultainer's Linear settings (`https://your-instance/api/webhooks/linear`).
2. Subscribe to **Issues** and **Comments**.
3. Copy the app's **webhook signing secret** into the Linear credentials in
   Consultainer (**Webhook signing secret**).

New and edited issues then update tasks within seconds, and Linear comments
appear on the task — labelled **From Linear**, notifying the assignee.
Deliveries are verified against the signing secret and rejected if older than
a minute.

## Sending changes to Linear

With **Send task changes to Linear** on (the default), a task created in
Consultainer — in the app, the REST API, or over MCP — becomes a Linear issue
in the linked team, with the link's Linear project and labels applied.
Title, description, status, and assignee edits are sent back too. If Linear
is unreachable, the change still saves in Consultainer.

Connections made before write access was requested are read-only; reconnect
from Settings → Integrations to enable this.

## Disconnecting

Disconnecting Linear stops syncing in both directions; tasks already pulled in
stay as they are.
