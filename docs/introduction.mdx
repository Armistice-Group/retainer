Consultainer runs client engagements for engineering consultancies — clients,
projects, tasks, time, milestones, expenses, and invoices in one place, built to
plug into the tools you're already building in rather than a separate admin app
you have to remember to update.

## What you can do

<CardGroup cols={2}>
  <Card title="Clients & projects" icon="building" href="/concepts/clients-and-projects">
    Track engagements, contacts, and the projects under each client — hourly,
    flat-fee, or milestone-based.
  </Card>
  <Card title="Time tracking" icon="clock" href="/concepts/time-tracking">
    Log hours against a project and task, with per-person bill rates and
    rate overrides.
  </Card>
  <Card title="Invoicing" icon="file-text" href="/concepts/invoicing">
    Generate invoices from unbilled time, completed milestones, or approved
    expenses — with payment terms, PO numbers, and QuickBooks sync.
  </Card>
  <Card title="MCP server" icon="bot" href="/mcp-server">
    Log time, check what's unbilled, and generate invoices straight from
    Claude Code, Cursor, or any MCP-compatible agent.
  </Card>
</CardGroup>

## How these docs are organized

- **Documentation** — core concepts (clients, projects, time, invoicing,
  milestones, expenses) and integrations (QuickBooks, Linear).
- **API Reference** — the REST API for scripting or integrating Consultainer
  with something else.
- **MCP Server** — connecting an AI coding agent so it can read and write
  your Consultainer data directly.

If you're setting up Consultainer for the first time, start with the
[Quickstart](/quickstart).
