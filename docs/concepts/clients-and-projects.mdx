title: Clients & Projects
description: How engagements, contacts, and projects fit together

## Clients

A client represents the company or person you're consulting for. Each client
can hold:

- **Contacts** — people at the client, with an optional email, phone, title,
  and role. Mark one as primary and/or set it to receive invoices.
- **Links** — staging URLs, shared docs, or Drive folders relevant to the
  engagement.
- **Documents** — files like a signed contract, W-9, or 1099 attached
  directly to the client record.

## Projects

A project belongs to a client and carries its own team, bill rates, and
billing type.

### Billing types

| Type | How it bills |
| --- | --- |
| **Hourly** | From logged, billable time entries at each team member's rate. |
| **Flat fee** | A single fixed amount for the whole project. |
| **Milestone-based** | Per deliverable — each milestone has its own amount and is billed once marked complete. |

### Team & bill rates

Each person on a project has their own bill rate and currency, set
independently of their rate on any other project. A time entry uses the
project member's standard rate unless a rate override is set on that
specific entry.

### Confidential projects

A project can be marked confidential, which restricts visibility to explicit
project members plus organization owners/admins — useful for engagements
under an NDA that shouldn't be visible to the whole team by default.

### Budgets

An hourly project can have a budget in hours. The project page shows hours
logged against that budget, and flags when it's close to or over.

Owners and admins get a notification (and a Slack message, if Slack is set up)
the first time a project reaches 80% and 100% of its budget, and when a task's
logged hours pass its estimate — the task's assignee is told too. Each alert
fires once; it can fire again if hours drop back under or the budget grows.

## Client-facing report links

From a project page, an owner or admin can generate a read-only, token-based
link for the client — no login required. It shows project status, hours vs.
budget, billing totals, and milestones, without exposing internal per-person
bill rates. The link can be regenerated or revoked at any time.

### Documents

Attach W-9s, 1099s, contracts and other paperwork (PDF or image, up to 5MB) to
a client. Click one to view it right in the app; **Download** saves it.

Each document has **Who can see it**: everyone in the organization, owners &
admins, or specific people. Owners and whoever uploaded it can always see it;
for everyone else, restricted documents don't appear and their files can't be
opened. Owners, the uploader, and admins who can see a document can change its
access or delete it. Every view and download is recorded in the audit log.

### Client links

A project's **Client link** (on the project page, owners and admins) is a
read-only page for the client: progress, budget burn, billing totals, invoices
and how to pay — no login, no internal rates. Turn on **Show tasks** to add the
project's task list (titles and status). Comments stay internal unless you tick
**Share with client** when posting one (or use **Share with client** on an
existing comment); only those appear under their task on the link.
